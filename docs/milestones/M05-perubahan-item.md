Tidak mengambil item lock sebelum unit, agar konsisten create/DB guard. No-op tidak menulis row/updatedAt/audit/unit tetapi menyimpan original result/key agar retry tidak mengembalikan state lama setelah edit berikutnya. Mutation/audit/strict result/completion rollback bersama, including SKU conflict/guard/fault. PENDING/FAILED/expired/incomplete/corrupt result tetap reserved/fail closed.
